oceanarray

oceanarray processes moored instrument records, from the raw files to quality-controlled CF-NetCDF, with an HTML report at each step:

  • Each instrument — the raw file, or an OceanSITES or RAPID RODB file from another group, read to netCDF (stage 1), trimmed to the deployment with clock corrections (stage 2), then QC flags, pressure for instruments without a sensor, salinity and velocity in east/north/up (stage 3).

  • Each mooring — every instrument on one time axis (the stack), then interpolated onto pressure levels (the grid).

  • Each site — the deployments of one site joined end to end (the Stack cat), and gridded one mooring per profile (the Grid cat).

  • Sharing — the stage-3 files and the grid as OceanSITES 1.4 files.

One command takes a mooring from its raw files to the grid and the report:

oceanarray run /data/proc/dsG3_1_2026 --raw-dir /data/raw

What a mooring is made of is written in one YAML file per mooring (The mooring YAML file); every setting and every step is recorded in the files it writes.

Start with Installation and the Quickstart. Until 1.0, variable names and attributes in the files can still change between releases; the changelog lists every change.
