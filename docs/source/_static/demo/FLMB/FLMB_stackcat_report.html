(4) Hydrography

Pressure, temperature and salinity for every deployment — one row each on a shared time axis. One colour per instrument (shared across rows, ordered by height) so a line can be followed through all three panels; the single legend spans the union of instruments. Values flagged 3, 4 or 9 (correctable bad, bad, missing) are left out; interpolated (8) and nominal (7) values are drawn. ADCP excluded from pressure. Grey bands are the turnarounds (no instrument in the water); a thin line marks each deployment's start, and each deployment is named along the top.
