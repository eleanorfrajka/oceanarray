Reading the grey background: where the file as first read uses the same units as the trimmed record, it is drawn in light grey, so you can check that the chosen window covers the time in the water. Grey may be absent for:

  • sensors without their own pressure (e.g. a MicroCAT using pressure interpolated from a neighbouring instrument): the interpolated pressure is added only when the record is checked, so the file as first read has none;
  • velocity in beam or instrument coordinates: an Aquadopp or ADCP set to record in BEAM or XYZ stores different variables from the east/north velocities shown here;
  • conductivity: when the units differ between the file as read and the checked record (e.g. S/m and mS/cm), the grey trace is left out rather than drawn on the wrong scale.
